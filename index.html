Portafolio de Proyectos

En esta sección se muestran algunos de los proyectos que he realizado durante mi formación académica.

Bloom

  • Nombre del proyecto: Bloom
  • Plataforma: Android
  • Herramienta de desarrollo: Android Studio
  • Descripción: Bloom es una aplicación de organización estudiantil diseñada para ayudar a los estudiantes a administrar sus horarios, tareas, calificaciones y actividades académicas de una manera más organizada.

Conociendo Santa Ana

  • Nombre del proyecto: Conociendo Santa Ana
  • Plataforma: Web
  • Herramienta utilizada: WordPress
  • Descripción: Conociendo Santa Ana es una página web creada con el objetivo de dar a conocer la comunidad de Santa Ana, mostrando información sobre sus tradiciones, costumbres, cultura y otros aspectos representativos de la comunidad.

Crunchy Vibes

  • Nombre del proyecto: Crunchy Vibes
  • Tipo de proyecto: Sistema de punto de venta
  • Plataforma: Escritorio
  • Herramienta utilizada: Visual Studio Code
  • Lenguaje utilizado: Python
  • Descripción: Crunchy Vibes es un sistema de punto de venta desarrollado para administrar la venta de galletas. El sistema permite registrar ventas, llevar un mejor control de los productos y organizar la información relacionada con el negocio.
